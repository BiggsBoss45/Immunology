DNA → RNA → PROTEIN GUIDE

DNA is transcribed into mRNA by replacing bases:

  • A → U
  • T → A
  • C → G
  • G → C

mRNA is then translated into amino acids using codons (3-base groups).

Example:
DNA: ATG → mRNA: UAC → Amino Acid: Met
